# Product catalogue: MG Car Audio demo store

`products.csv` is generated by `build_products.py`. Don't edit the CSV by hand (and don't re-save it in Excel); edit the script and run:

```bash
python3 mg-car-audio/data/build_products.py
python3 mg-car-audio/data/validate_data.py --check-urls   # must end "OK: no errors"
```

**59 products, 107 variants, 66 images.** Every product is Active and published to the online store.

## Import steps

1. **Metafield definitions first** (docs/SETUP.md §4.4): Settings → Metafields and metaobjects → Products → add `custom.car_make` (single line text, **list**), `custom.car_model` (single line text, **list**), `custom.screen_size` (single line text), `custom.fitted_price` (single line text), each with Storefronts access. Without them the metafield columns are ignored or rejected. The car makes used are: BMW, Audi, Mercedes-Benz, Volkswagen, Universal, Toyota, Lexus, Nissan, Honda, Mazda (don't add preset-choice validation, or it must allow exactly these).
2. Validate: `python3 mg-car-audio/data/validate_data.py --check-urls`.
3. **Products → Import → Add file → `mg-car-audio/data/products.csv`**. Tick **Overwrite products with matching handles** if the old 20-product import is already in the store (the 20 original handles are unchanged, so they update in place). Tick **Publish new products to all sales channels** if offered.
4. **Upload and preview**: it should say **59 products**. **Import products**. Shopify downloads 66 images from Wix, Unsplash and the theme CDN; you get an email when it's done.
5. **No metafield definitions, or the metafields didn't import?** Import `products-no-metafields.csv` instead (same products, no metafield columns), then add the four metafields in **Bulk edit** (list values separated by commas). Without them, product cards lose the "Fits BMW" and "or €X fitted" lines.
6. Create the 12 automated collections (SETUP §6) if they don't exist yet: they fill themselves from the tags.
7. **Gift card:** the voucher row has `Gift card = TRUE`. If the import rejects it, delete it and create it in **Products → Gift cards** (€50 / €100 / €250, tag `gift-vouchers`).

**After, check:** Products shows 59, all Active; filter by tag `demo-placeholder` = 43, `mg-shop` = 3, `demo-price` = 3. Open **MG Select Front & Rear Dash Cam**: 2 variants (€179 / €288), Fitted price €288. Open **Reverse Camera Installation**: 4 variants, 2 images.
